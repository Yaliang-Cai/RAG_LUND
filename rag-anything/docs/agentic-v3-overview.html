Agentic RAG v3

LLM-driven retrieval agent · built on RAG-Anything + LightRAG

Replaces the fixed retrieval pipeline with a real agent loop: the model decides which tool to call, with what query and budget, accumulates evidence across steps, self-grades coverage, and answers only when the evidence supports it — under a hard cost / time budget, with per-turn session memory for multi-turn conversations.

Minimal retrieval toolset

search
LightRAG local + global KG fused with hybrid (dense + BM25) chunk vectors, reranked at admission. Default for facts, entities, definitions, summaries.
search_multihop
Personalized PageRank over the entity graph for bridge / comparison / causal reasoning. No rerank — PPR already ranks by multi-hop relevance.
answer
Finish and generate from gathered evidence (direct · map-reduce · CoT-reflect).

Why it is better

  • Evidence accumulates across steps; reranking is incremental (no repeated work).
  • Fact ledger drives coverage and targeted re-retrieval; abandons unverifiable details instead of looping.
  • Grounding by citation — claims checked verbatim against sources by code, not self-judged.
  • Budget-aware: cost-points + wall-clock + token guardrails; fast-path for simple questions.
  • Session memory: coreference resolution + cross-turn evidence cache.
  • Answers in the user's language; full chain trace per turn in Phoenix.
